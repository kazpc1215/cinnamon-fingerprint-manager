# 国際化とアクセシビリティ

## 現在の状態

UI の文言は日本語を基本としています。fprintd の出力（`enroll-completed` など）は
英語のまま表示されますが、判定には `LC_MESSAGES=C` で安定した英語のマーカーを
使っています。デバイス名や指の内部名は fprintd が返す値をそのまま表示します。

## 翻訳を追加する場合

現在は gettext のカタログを同梱していません。翻訳を追加する場合は、次の順序で
進めると差分を追いやすくなります。

1. UI 文字列を一元管理する（例: `gui.py` 内の定数、または gettext の `_()`）
2. `locale/<lang>/LC_MESSAGES/` に `.po` / `.mo` を追加
3. ビルド時に `.mo` を wheel / install.sh の配置対象へ含める
4. 日本語・英語の両方で起動確認する

fprintd の解析に使う文字列（`verify-match` など）は翻訳せず、そのまま比較して
ください。表示用のメッセージだけを翻訳対象にします。

## アクセシビリティ

- 主要なボタンにはツールチップを設定しています
- 指紋一覧と fprintd 出力にはアクセシブル名を設定しています
- エラーや進捗はステータスラベルと出力欄の両方に表示されます
- キーボード操作は GTK の標準フォーカス移動に従います

改善提案（スクリーンリーダーでの読み上げ順、コントラスト、キーボードショートカット
など）は Issues へお寄せください。
